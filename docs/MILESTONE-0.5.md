# Discovery and build depth milestone

The second specification review found that working baseline features still left several explicit requirements shallow. This milestone completes a reviewable slice while keeping the game playable.

1. Add data-defined specialization effects that change casting and kill behavior; retain normalized PvP fairness.
2. Persist discovery facts independently of the bounded analytics log. Add quests for elemental relationships, unassisted discoveries, diverse chains and winning with a reaction learned today.
3. Add daily elemental practice, victory and chain objectives with once-per-day server-validated rewards.
4. Complete four-stage conditional hints, laboratory autocomplete, known-recipe preparation, and a persistent first-session guide.
5. Expose collection usage and build state in the codex and turn actual battle contributions into next-experiment guidance.
6. Verify engine behavior, saving, account reward limits and desktop/mobile flows; update the coverage report with evidence.
7. Complete artifact rarity and collection-chain indicators, award achievement resources once, and reward experiment-challenge authors when other players solve their challenge.

Human campaign duration, physical-device rendering performance and long-term player outcomes remain separate validation work.

Completed as version 0.5.0. Strict TypeScript and content validation pass. Verification covers 208 engine/server tests, 28 desktop/mobile browser tests, and 5,600 seeded balance simulations. Screenshots reviewed include the laboratory scenario, detailed collection, achievement rewards and rare discovery. See COVERAGE.md and IMPLEMENTATION.md for exact behavior and qualifications.
